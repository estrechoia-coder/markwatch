Why this exists

Deadlines you can miss

Office actions carry strict response deadlines. Trademark attorneys and brand teams pay people to watch dockets for exactly this.

Silent abandonment

Marks get abandoned or go dead without fanfare — and someone else can pick up the name while you're not looking.

Similar marks appear constantly

New applications hit USPTO every day. Watching for confusingly-similar marks by class is manual, repetitive work.

Planned API

Status lookup

Serial number, registration number or owner name → current status, dates, classes, assignments. Clean JSON.

Watch lists

Watch any set of marks (or owner names / classes) and get alerted the moment status changes.

Webhook alerts

Status changes pushed to your webhook or email. No polling, no babysitting.

Honest limits

Planned roadmap: owner/assignee data, class-based similar-mark scanning, bulk export. Not all shipped on day one.

FAQ

Is this live right now?

No. This page is a demand test: we're checking whether developers and brand teams actually want this before we spend time building it. The API does not exist yet.

Where does the data come from?

USPTO's public trademark systems (TSDR and the Open Data Portal). That data is public domain — the problem is that it's awkward to consume, which is the gap MarkWatch would fill.

Is this legal advice?

No. MarkWatch is a data and alerting tool. It does not provide legal opinions on trademark matters.

Why do you ask which plan I'd choose?

To measure real demand. A waitlist tells us you're curious; a chosen plan tells us you'd pay. We report these numbers honestly, including if they're low.

What happens to my email?

Used only for launch notification if the product ships; never shared, never sold. If the product is not built, your email is deleted.
